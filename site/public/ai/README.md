# How Economics Absorbed AI

Generated Quarto output published verbatim at
<https://www.lukasikic.info/ai/>.

- Source repository: <https://github.com/lusiki/AI_econ_resources>
- Generator recorded in the output: Quarto 1.6.43
- Source refresh: `Rscript scenario/R/build_metrics.R`
- Site render: `quarto render scenario`

The generated CSV files in the source repository allow the Quarto site to
render without the private SQLite corpus. The local `prepare:ai` script adds
main-site navigation and public metadata after a render; it is idempotent and
runs automatically before the Astro build.
