The part of the collection worth handing to someone else

Resources

This is not the whole collection. The pipeline indexes anything on AI and economics worth a record, and it keeps the dead ends too, because a record of a dead end is still a record. This page is the shorter list that survives a second question: would I point someone else at this? 445 items answered yes.

That question has no measurement behind it. Every other number on this site is recomputed from the database when the page builds, but inclusion here is a judgment, and it is one person’s. It was formed by what the curator happened to be working on, which means the list shows the mapmaker’s routes as much as it shows the territory. Exclusion is not a verdict. A great deal of good work is missing from this page for no better reason than that it never crossed this desk.

The unit is the work, not the URL. The same argument arrives as a working paper, then a journal article, then a recorded talk, then a thread about the talk. Those are one work wearing four hostnames, and the list carries the version worth reading rather than all four. What survives spans 6 categories and 245 named authors, which is wide enough that no single register (papers, tools, guides, talks) sets the tone on its own.

The columns are measured even though the selection is not. Title, author, type, category and date are bibliographic facts read from the database, never hand-typed. The last column is the strict one: it reports whether the complete document is actually held as text, which is true of 354 of these 445 (80%). A link that resolves is not a document, and a page that merely points at content counts as not held here. For the full census behind this selection, and an honest account of what it cannot see, see What can be read and Method.
