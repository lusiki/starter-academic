## Sector report library

The sector section at `#sectors` connects both media intelligence pages to the
library at `/media-intelligence/sectors/` and `/hr/media-intelligence/sectors/`.
The library uses the media page's editorial typography, dark panels and lime
accent. Merkat Media is credited as the report series, with analysis by Luka
Šikić. The Autumn 2026 edition covers September 2025–August 2026.

Unlike the original standalone media pages, the library is generated by Astro:

- `site/src/components/SectorLibrary.astro`: shared bilingual page, reading
  guide, report disclosures and progressively enhanced filters.
- `site/src/data/sector-reports.ts`: sector names, editions, translated
  summaries, sample sizes, headline figures and PDF page counts.
- `site/public/media-intelligence/sectors.css`: library styles and the sector
  entry section on the existing media pages.
- `site/public/media-intelligence/reports/autumn-2026/`: the six original
  Croatian PDFs, copied without alteration. Both languages share these files.

The two Astro routes enter the sitemap automatically. All report summaries,
native disclosures and PDF links work without JavaScript. Filters appear only
when JavaScript is available; an edition filter appears automatically once the
catalogue contains more than one edition. Direct report anchors remain
accessible after filtering and are preserved by the language switch.

### Adding a sector or edition

1. Add a new sector to `sectorNames`, or an edition to `reportEditions`, with
   English and Croatian labels. Keep existing keys to preserve old links.
2. Copy the original PDF to
   `site/public/media-intelligence/reports/<edition>/<sector>.pdf`.
3. Add a record to `sectorReports`, including both languages, the correct
   article denominator, percentage, company scope, PDF page count and source
   page (`summaryPage`). Each
   sector/edition pair must be unique. Array order controls presentation;
   place a new edition before older editions if it should appear first.
4. Verify the headline statistic against the original PDF. The six initial
   reports cite their page 2 summaries; set `summaryPage` to the correct source
   page for each new report. The featured energy chart is explicitly dated Autumn 2026
   and cites page 5; change its data, source and caption together if replacing it.
5. Update the curated `#sectors` entry on both standalone media pages when
   featuring a new sector or edition. Its links use
   `#<sector>-<edition>`. The library itself needs no layout changes.
6. Run the validation pipeline and check the new PDF, translated copy,
   filter combinations, direct anchors, and desktop and mobile layouts.

Do not add sector totals together or present theme percentages as comparable
market shares. The six reports have different source sets and selection rules;
themes can overlap. Preserve the individual period, denominator and caveats.
